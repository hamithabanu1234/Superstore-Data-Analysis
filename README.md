# Superstore-Data-Analysis
Superstore sales dashboard using Excel and Power BI
# 📊 Superstore Sales Analysis

## 📁 Dataset
[Kaggle - Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)

## 🧰 Tools Used
- Microsoft Excel (Data Cleaning)
- Power BI (Visualization & Dashboard)

## 🎯 Objectives
- Analyze sales, profit, and discounts
- Compare performance across regions and categories
- Visualize insights for business decision-making

## 📊 Visuals Created
- Sales by Region and Category
- Monthly Trend of Sales
- KPI Cards (Total Sales, Total Profit, No. of Orders, Avg. Profit Margin)

## 📝 Outcome
Developed a dynamic retail dashboard using excel and Power BI, showcasing data cleaning and visualization skills.
