# 📊 Superstore Sales Analysis (Excel Project)

## 📁 Dataset
- Source: [Kaggle - Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
- File: `Sample - Superstore.xls`  
- Contains retail sales data including order details, profit, sales, region, category, and more.

## 🧰 Tools Used
- Microsoft Excel

## 🎯 Objective
To analyze retail sales data and extract business insights by:
- Identifying sales trends
- Comparing regional performance
- Highlighting profitable product categories
- Finding discount-impact on profitability

## 🔧 Data Cleaning Steps
- Removed duplicates and blank rows
- Fixed date formatting (Order Date, Ship Date)
- Handled missing values
- Standardized column formats (e.g., numbers, currency)
- Used power query

## 📊 Analysis Performed
- Pivot Tables for:
  - Sales by Region
  - Sales and Profit by Category & Sub-Category
  - Monthly Sales Trend
- Conditional Formatting to highlight low-profit products
- Calculated Fields:
  - Profit Margin
  - Discount Effect
- Charts Created:
  - Column Chart: Sales by Region
  - pie Chart: Monthly Sales Trend

## 🚀 Outcome
Delivered a comprehensive Excel-based sales report for a fictional retail store. Demonstrated core skills in data cleaning, pivot tables, calculated metrics, and chart-based visual storytelling.
